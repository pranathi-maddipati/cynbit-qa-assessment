# Technical Setup and Testing Notes

## 1. Application Under Test

- Website: https://www.cynbit.in
- Testing Type: Manual Web Application Testing

## 2. Test Environment

| Component       | Details                       |
|-----------------|-------------------------------|
| Device          | Dell Inspiron 15 3000 Series  |
| Operating System| Windows 11                    |
| Browser         | Google Chrome                 |
| Desktop Testing | Laptop browser                |
| Mobile Testing  | Chrome mobile device emulation|

## 3. Setup Requirements

No additional software installation, programming environment, or external dependencies are required to review this assessment.

The website can be accessed directly through a web browser.

## 4. Testing Procedure

1. Open https://www.cynbit.in in Google Chrome.
2. Navigate through the website pages and sections.
3. Test buttons, links, navigation, forms, dropdowns, and interactive elements.
4. Enter valid and invalid inputs to check form validation.
5. Check selected pages using Chrome mobile device emulation.
6. Record observed issues with reproduction steps, actual results, and expected results.
7. Capture screenshots for selected findings.

## 5. Assessment Deliverables

- QA Audit Report
- Bug and Issue Report
- Improvement Recommendations
- Supporting evidence screenshots

## 6. Important Note

This assessment documents manual testing observations. No automated test scripts or payment transactions were executed as part of this assessment.
