# Cynbit Website – QA Testing Assessment

## 1. Project Overview

This repository contains the QA testing assessment of the Cynbit website (https://www.cynbit.in).

The objective was to evaluate website functionality, form validation, navigation, usability, and mobile responsiveness, and to
document the issues identified during manual testing.

## 2. Testing Scope

The testing covered the following areas:

- Homepage
- Company pages
- Careers
- Services Hub
- Product Suite
- Case Studies
- BitElevate Ecosystem
- BitElevate Learning Paths
- BitElevate Student Diaries
- Blog
- Contact page
- Header and footer navigation

## 3. Testing Approach

Manual testing was performed using:

- Functional testing
- Positive and negative input testing
- Form validation testing
- Navigation testing
- Responsive testing
- Usability testing
- Keyboard interaction testing

## 4. Test Environment

| Component        | Details                       |
|------------------|-------------------------------|
| Operating System | Windows 11                    |
| Device           | Dell Inspiron 15 3000 Series  |
| Browser          | Google Chrome                 |
| Desktop Testing  | Laptop                        |
| Mobile Testing   | Chrome mobile device emulation|

## 5. Key Findings

The assessment identified issues related to:

- Phone number fields accepting invalid alphabetic or special-character-alone values.
- Date of Birth field accepting future dates.
- Inquiry form accepting numeric-alone values in Full Name and Message fields.
- Side panels not closing when the Escape key is pressed.

Detailed steps, actual results, expected results, severity, and priority are documented in the Bug & Issue Report.
